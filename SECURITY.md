# Security

Please report a security problem in Seerr AI privately, through this
repository's **Security** tab → **Report a vulnerability**, not in a public
issue. Include what can be reached or changed, by whom (signed out, any
user, an admin), and the steps.

A problem that is also in Seerr itself is best reported to
[Seerr](https://github.com/seerr-team/seerr/security) as well, so it is fixed
for everyone.

Only the newest release, and the `dev` branch, receive fixes.
